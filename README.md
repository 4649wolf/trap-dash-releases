# TRAP DASH

PC向けの対戦・協力アクションゲームです。

- [ブラウザで遊ぶ](https://trap-dash.pages.dev/)
- [Windows版のダウンロード案内](https://trap-dash.pages.dev/downloads.html)
- [最新版の配布ファイル](https://github.com/4649wolf/trap-dash-releases/releases/latest)

## Windows版

通常は **TRAP-DASH-Setup.exe** を使用してください。ユーザーごとにインストールし、起動時に最新版を確認します。更新のダウンロードと再起動は、アプリ内で選択できます。ゲーム中に強制的に再起動しません。

**TRAP-DASH-Portable.exe** はインストール不要の単体起動版です。こちらは自動更新せず、新しいexeに置き換えて更新します。

旧単体版をお持ちの方も、初回だけインストール版をダウンロードする必要があります。

Windows 10/11 64bit向け。音源とゲームを同梱し、オフラインで練習できます。オンライン対戦・協力には通信が必要です。配布ファイルはコード署名証明書なしで提供しているため、Windowsの警告が表示される場合があります。

## ファイルの確認

各リリースの `SHA256SUMS.txt` で配布ファイルのSHA256を確認できます。`latest.yml` と `.blockmap` はアプリの更新用です。

このリポジトリは配布専用です。ゲームソースや運営用の認証情報は含みません。
